# Simple PHP CMS

Эта CMS не требует базы данных и позволяет управлять контентом через простую админ‑панель.

## Запуск

Скопируйте файлы на сервер с PHP 8.3. Перейдите по адресу `/admin/login.php`, используйте логин `admin` и пароль `password`.

## Структура

- `blocks/` — html‑блоки
- `templates/` — html‑шаблоны
- `pages/` — страницы сайта
- `history/` — версии файлов
- `css/style.css` — стили админки

## Использование

Создавайте блоки и шаблоны, вставляйте блоки через `{{block:имя}}`. При каждом сохранении создаётся версия файла в каталоге `history/`. Максимальное количество версий настраивается в `history/settings.json`.

Главный шаблон находится в `templates/index.html`. Главная страница сайта собирается из блока `header`, `content`, `footer` в файле `index.php`.
